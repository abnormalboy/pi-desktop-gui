# v0.9.0 应用更新验收

日期：2026-10-15。范围：PRD U1；v0.10 / v0.11 未纳入本版。

## 实现与隔离

- `UpdateService` 管理更新策略，`update-driver` 适配 electron-updater 6.8.9，`Updates.tsx` 展示独立更新状态。Pi 的版本策略和进程协议没有改动。
- Windows 同时生成 NSIS 安装版和便携版，仍使用原 appId、productName 和数据目录；Linux 保留 AppImage/deb；macOS 保留未签名 dmg/zip。
- 安装前阻止尚未结束的任务、审批和受理中的操作，保存最新草稿、断开 Pi 并等待写盘。升级前保留原始索引；未知的新格式只读打开，不覆盖数据。
- 所有模型测试使用本地服务。升级测试打包两份生产应用，只在测试构建时替换应用标识、数据目录和更新源；下载和更新说明都来自回环服务，应用的其他 HTTP 请求会被拦截并使测试失败。

## 证据边界

- 本次升级回归使用隔离的 0.9.0 / 0.9.1 测试包和本地更新源，不表示已发布公开的 0.9.1。
- macOS 的提示界面经过本地 UI 状态测试，macOS 后端与构建经过 CI；未在真实 Mac 桌面上手动试用，也未增加签名或自动替换能力。
- 系统关机时禁用安装由生命周期代码检查确认，没有在测试中真正关闭操作系统。
- Windows 安装包未签名，原生更新器校验下载内容的 SHA-512，不能据此证明发布账号未被盗用。首次采用自动更新需手动安装本版。
