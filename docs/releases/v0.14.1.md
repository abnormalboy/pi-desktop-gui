# Pi Desktop v0.14.1

本版修复 Windows 进程退出与会话切换的边界问题，完善模型选择、应用图标和跨平台回归验证。

## 本版变化

- 修复 Windows 上 Pi 已正常退出、但结束进程树的请求稍后返回“找不到进程”时，关闭流程仍报错的问题；无法确认工具子进程已结束时，仍保持恢复操作的安全限制。
- 修复空闲会话切换及 Pi 重新连接期间误显示“另一个会话正在执行”的提示。
- 当前任务执行期间可选择模型，新模型从下一次请求生效，不中断当前回复；连接、停止及会话切换确认期间仍受保护。
- 修正 Windows 窗口和任务栏的应用标识与原生多尺寸图标。
- 稳定聊天回归测试的会话定位和草稿恢复断言；会话切换的 200 毫秒性能验收门槛保持不变。
- 更新中英文 README、演示录制脚本和贡献说明。

## 下载与更新

- Windows x64：推荐使用 `Pi-Desktop-0.14.1-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.1-win-x64.exe`。
- macOS：按芯片选择 `arm64` 或 `x64` 的 `.dmg` / `.zip`。
- Linux x64：选择 `.AppImage` 或 `.deb`。
- Windows 安装版和 Linux AppImage 支持应用内更新；其他安装方式请从发布页下载。`SHA256SUMS.txt` 提供发布资产的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent。完整功能回归使用 Pi 1.1.0；本版不会自动安装或升级 Pi。macOS 安装包仍未签名、公证，首次打开方式见 README。

本版未调整会话切换性能指标，也不包含性能诊断实验。
