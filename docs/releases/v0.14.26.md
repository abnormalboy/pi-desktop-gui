# Pi Desktop v0.14.26

本版修复 Windows 更新后仍启动旧版的问题，保留 v0.14.24 的会话生命周期、退出保存和会话切换改进。

- 更新以当前运行程序所在目录为目标。另一目录还装有同一个 Pi Desktop 时，只更新当前这一份，保留另一份的文件、安装信息和快捷方式。
- 更新后直接启动本次更新的程序。正常安装流程会修正仍存在的开始菜单和桌面快捷方式，同时保留用户主动删除快捷方式的选择。
- 从解压目录发起更新时，先校验全部解压文件，再覆盖当前目录；文件缺失或损坏会在覆盖前停止，并提示重新下载。
- 升级验收覆盖正常重启、旧快捷方式、两个程序目录共存、便携版转安装版和退出时安装，并验证解压文件损坏时两个目录的原文件均不变。Windows 验收使用解析后的实际目录，避免长短路径表示不同造成误判。

升级说明：旧版更新器没有传递自身运行目录。从非注册目录运行的旧版，首次自动更新仍可能更新注册目录；请先将包含修复的完整程序放入预期目录，后续自动更新才会以该目录为准。从正常安装目录运行的用户可以照常自动更新。

发布继续执行三平台测试、Windows/Linux 升级回归、安装包及更新元数据校验。
