# Pi Desktop v0.14.0

本次集中发布 PRD v0.11–v0.14：按轮次撤销、精确文件引用、细粒度审批、会话查找、工作区变化提醒，以及桌面交互、项目规则、模板和本地用量管理。

### 文件与撤销

- 每轮对话建立文件检查点，最多保留 20 轮，按 7 天和 200 MiB 配额清理；可预览并恢复到指定轮次之前。
- 手动修改或无法确认来源的文件默认不勾选。恢复前再次核对文件状态，防止确认期间的新修改被覆盖；已提交内容会作为新的未提交差异恢复，不改写 Git 历史。
- 文件恢复后可另行选择回到对应消息。命令产生的数据库、网络、安装等副作用不属于文件撤销范围。
- 支持 `@文件:10-40` 和 `#L10-L40` 行范围引用、预览行选择、差异片段追问；文件变化会提示刷新，并保留预览滚动位置。

### 更方便地阅读和操作

- `Ctrl+F` / `⌘F` 查找整个当前会话，覆盖历史分页、思考、工具参数与输出；增加轮次目录和连续只读工具分组。
- 左右面板和文件列表/预览比例可直接拖动、键盘调整及双击复位，预览可最大化。`Ctrl+J` / `⌘J` 开合右栏，`Alt+1/2/3` 切换页签。
- 项目独立展开、状态徽标、旧会话收纳、文件过滤与变更标记；代码块增加语言、行数、复制和换行控制，对照差异按行对齐并突出字符变化。
- `@` 文件选择支持键盘操作；长文本粘贴折叠后仍完整保存，输入区显示容量估算；图片支持缩放、切换和复制。

### 授权与项目管理

- 可以按命令前缀或完整命令授权，复杂 Shell 语法只按完整命令授权；项目写入授权仍排除项目外、敏感文件和链接逃逸目标。授权可逐项撤回，切换会话即清空。
- 文件面板显示项目规则，并可显式创建 AGENTS.md 草稿；常用验证命令可从工具卡片或输出面板重跑，沿用当前审批模式。
- 可视化创建、编辑和删除 Pi 原生提示词模板，并填写参数；更新立即重新加载 Pi 命令列表，包内模板只读。
- 上下文达到 75% / 90% 时显示提示，并可压缩或创建会话副本。用量页汇总本地会话的 token 和费用；按最后活动日期选择会话，缺失统计明确显示，不等同于服务商账单。
- 清理空会话前确认，并保留活动会话、置顶、草稿、附件、图片及有历史内容的记录。

Pi CLI 不再按主次版本硬拦截：1.2 和其他可识别版本可连接，未完成回归的版本显示“未验证”，实际协议响应仍会校验。完整功能回归使用 Pi 1.1.0，不代表已经完整验证 1.2；本次不自动安装或升级 Pi。Windows 推荐安装版，安装版与 Linux AppImage 支持应用内更新；macOS、deb 与便携版通过发布页手动下载。
