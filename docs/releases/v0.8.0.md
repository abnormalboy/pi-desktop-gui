# Pi Desktop v0.8.0

本版完成本地恢复、界面模块拆分和 Pi 补丁版本兼容。

- 本地会话索引损坏时保留原文件并尝试恢复备份；坏项目或会话逐条处理，其余数据仍可使用。最多保留三份备份，间隔至少十分钟，恢复提示会说明时间与丢弃条目数。
- 数据目录无法写入时进入只读状态，禁止发送；写盘刚失败也不会放行新的模型请求。
- Pi 意外退出后显示退出原因、最后的工具、日志和本轮变更。可以重连、编辑续写提问后继续，或检查并撤销文件。没有自动重发原任务；尚未执行的队列文字和图片会回到草稿。
- 运行中仅 Pi 主进程退出时，工具可能仍在改文件。无法确认命令结束时会暂停恢复和撤销；请先手动结束残留命令再重启应用。仅重启应用不会结束旧命令。
- 界面拆成组件、hooks、功能页签和样式模块，保留消息缓存与增量更新。Linux CI 增加三套界面测试和失败截图。
- 支持 Pi 1.1.x 补丁版与同线预发布版；1.1.0 是完整回归基准。过旧、过新、无法识别的版本给出明确说明和可复制安装命令。核心 RPC 响应与桌面适配扩展增加协议检查，每周测试最新 1.1 补丁版。

已有会话与配置继续使用原数据目录。恢复到备份时，备份时间之后的草稿改动可能丢失；Pi 自身的 JSONL 历史不会被索引恢复修改。
