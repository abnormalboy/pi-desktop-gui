# Pi Desktop v0.14.21

本版改善思考过程、工具操作与侧边栏的可读性，保守复用未使用的空白对话，并增加更新结果提示与失败恢复保护，保留 v0.14.20 的重试、用量和导出修复。

- 同一轮回复的思考内容合并到一个可折叠区域，保留原始顺序，完成后默认收起，并提供批量收起入口。搜索可定位并重新展开命中内容；纯思考结束或取消的回复仍保留模型、用量和重新生成操作。
- 思考使用界面字体，代码与工具输出采用统一等宽字体栈，相关文本调整为 13px 基准字号和更宽松行高。没有下载或捆绑额外字体；Windows 不同 DPI、ClearType 和字体回退的实际观感仍待用户验收。
- 工具输出的复制和查看文件改为带可访问名称的紧凑图标按钮。复制成功有反馈，失败会明确提示并允许再次操作。
- 移除侧边栏底部重复的打开项目入口，保留项目标题旁添加入口和空状态引导，统一右侧操作按钮对齐。
- 同一作用域重复新建时，只复用尚未使用、未连接且没有历史文件的占位对话。草稿、附件、图片、自定义标题、置顶、模型、思考与审批设置等均受保护。既有空对话不会自动删除，手动清理仍需确认；空会话自动回收尚未实现。

- Windows 安装版显式重启更新使用可见的一键安装过程；普通退出时的更新方式不变。下次启动只读取七天内的一条最小版本尝试记录，过期记录在读取时清除。运行版本仍未达到目标版本时显示“结果待确认”及重新检查/下载入口，不将取消、仍在安装或旧副本误判为确定失败。更新准备失败后，原窗口的文件变更通知继续工作。该保护适用于运行本版后发起的新更新，无法补记旧版已经发生的尝试。

新增回归覆盖思考聚合、搜索、分页、流式与取消/重新生成、真实剪贴板反馈、布局对齐及空会话并发保护。发布继续执行三平台功能检查、Windows/Linux 升级回归、打包及更新元数据校验。

v0.14.18 → v0.14.19 的用户现场更新失败原因仍在调查，本版修正的是已证实的更新结果可见性与恢复缺口，不宣称已经定位该现场根因。也不宣称已解决所有会话切换性能尖峰，或将 Linux 字体截图等同于 Windows 原生渲染验收。
