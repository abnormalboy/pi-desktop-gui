# Pi Desktop v0.14.3

本版改善桌面主题一致性，并修复 Pi 设置页的编辑、读取及保存状态问题。

## 本版变化

- Windows/Linux 标题栏与菜单入口跟随浅色、深色或系统主题，保留原生窗口按钮、窗口拖拽及原生菜单功能；macOS 保留原有窗口控件和关闭后隐藏行为。
- 删除会话等业务确认使用应用内主题弹窗。取消、Escape、关闭及页面重新加载均不会确认操作；执行中的任务退出仍需明确确认，界面不可用时保留安全的原生退出确认。
- 修复重复点击当前配置页导致内容清空或不可编辑的问题。本地配置可在 Pi 运行时编辑，保存与应用仍遵守任务、存储和恢复状态限制，并显示禁用原因与启用指引。
- 完善配置范围切换、迟到读取和保存失败的处理，保护未保存内容；区分“配置已保存”与“已应用到 Pi”，避免连接失败掩盖已完成的保存。
- 增加跨平台主题、原生菜单与窗口状态、确认生命周期，以及配置读写竞态回归检查。

## 下载与更新

- Windows x64：推荐使用 `Pi-Desktop-0.14.3-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.3-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.3-mac-arm64.dmg` / `.zip`，Intel 芯片选择 `Pi-Desktop-0.14.3-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.3-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.3-linux-amd64.deb`。
- Windows 安装版和 Linux AppImage 支持应用内更新；其他安装方式请从发布页下载。`SHA256SUMS.txt` 提供发布资产的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent。完整功能回归使用 Pi 1.1.0；本版不会自动安装或升级 Pi。macOS 安装包仍未签名、公证，首次打开方式见 README。

## 验证边界与已知问题

- 主题相关自动检查覆盖三平台原生 API、菜单功能、窗口状态及应用界面。原生菜单的实际像素外观、窗口按钮鼠标操作，以及实际系统主题变化后的同步仍待实机人工验收；[#1](https://github.com/yeyuProject/pi-desktop-gui/issues/1) 保持开启。
- 历史会话切换性能尖峰尚未完全归因或解决。200 毫秒目标继续采样，超限暂作可见告警；功能正确性、构建及升级测试仍为发布必过项。本版不承诺所有切换低于 200 毫秒。
