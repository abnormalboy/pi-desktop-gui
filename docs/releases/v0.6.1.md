# Pi Desktop v0.6.1

本版修复消息气泡的垂直间距，并更新工具调用显示与应用图标。

## 本版变化

- 修复纯文字消息下方多出 12px 留白的问题：无图片时不再保留空图片容器，上下留白恢复一致。
- 调整连续工具调用、展开内容之间的连接线，以及运行中输入框的边框和动画提示。
- 启用新的翡翠绿 π 与终端光标图标，统一应用窗口和各平台安装包；Windows ICO 提供九种尺寸，覆盖常见屏幕缩放比例。
- 补充 v0.7 候选方案文档，相关功能尚未开发，不属于本版功能。

## 下载与运行

- Windows x64：下载 `Pi-Desktop-0.6.1-win-x64.exe`，关闭旧版本后双击运行。
- macOS：按芯片选择 `arm64` 或 `x64` 的 `.dmg` / `.zip`。
- Linux x64：选择 `.AppImage` 或 `.deb`。
- `SHA256SUMS.txt` 提供所有安装包的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent 1.1.0：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@1.1.0
```

Windows 还需要 Git for Windows。macOS 安装包暂未签名、公证，首次打开方式见仓库 README；Linux AppImage 首次运行需授予执行权限。安装包不包含 Pi CLI 或模型账户凭据。
