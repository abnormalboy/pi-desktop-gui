# Pi Desktop v0.14.2

本版减少已连接会话切换时的一处显示等待，并完善 Skills、扩展与提示词模板的资源管理体验。

## 本版变化

- 切换到已连接且内容已就绪的目标会话时，立即向界面发布选中状态，不再等待会话保存完成后才显示。保存仍按队列执行，保存错误仍会传递，历史读取与切换调用的完成仍等待持久化；未连接目标的处理保持原有顺序。
- 资源列表展示 Skills 和提示词模板的名称与简短说明，提示词模板另显示参数提示；支持按资源类型筛选并查看分类数量，搜索可匹配说明、来源及路径。
- 资源条目可定位到本机文件，设置页新增 Skills、扩展与提示词模板的管理入口。
- 新增 9 项会话切换回归测试，覆盖保存中的状态通知、连续切换、保存失败、退出等待和未连接目标等边界；修正文件监听测试对通知时序的假设，不改变产品的文件监听行为。
- 持续记录会话切换耗时，超出 200 毫秒目标暂作告警，功能正确性、构建及升级测试仍为发布必过项。

## 下载与更新

- Windows x64：推荐使用 `Pi-Desktop-0.14.2-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.2-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.2-mac-arm64.dmg` / `.zip`，Intel 芯片选择 `Pi-Desktop-0.14.2-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.2-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.2-linux-amd64.deb`。
- Windows 安装版和 Linux AppImage 支持应用内更新；其他安装方式请从发布页下载。`SHA256SUMS.txt` 提供发布资产的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent。完整功能回归使用 Pi 1.1.0；本版不会自动安装或升级 Pi。macOS 安装包仍未签名、公证，首次打开方式见 README。

本版只消除已确认的一处显示阻塞。历史上观察到的 619.8 毫秒会话切换尖峰与底层保存耗时原因仍未完全解决；本版不承诺所有切换低于 200 毫秒，也不包含性能诊断探针。
