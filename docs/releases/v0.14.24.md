# Pi Desktop v0.14.24

本版改进新建空会话的生命周期，并补齐会话切换的分场景测量。保留 v0.14.23 的模型目录读取、环境检测和推理级别行为。

- 未使用的新会话只作为当前进程中的占位，不写入会话索引或轮换备份。离开后侧栏隐藏该占位；同一项目再次新建时可复用其原 ID。
- 输入草稿、添加附件或图片、修改会话设置、重命名、置顶、主动连接或发送任务后，会话立即成为正式记录。即使随后清空、取消或操作失败，也不会自动回收。延迟到达的草稿仍归原会话，不会写到当前新会话。
- 历史空会话不会自动删除。手动清理入口移到“设置 → 诊断与数据”，继续保留确认、运行状态检查和删除前内容复查。
- 普通退出会等待全局存储队列与已接受操作完成，覆盖尚未创建 Pi 服务时的首次草稿写入。保存失败时明确提示，未获得明确丢弃确认不会静默退出；已经关闭会话服务的失败路径会说明窗口仅用于复制仍可见的内容。
- 测量分别覆盖首次打开、同项目切换、跨目录冷/热访问、大历史记录及快速 A-B-A。目标内容 DOM、后续动画帧、选择完成、模型目录读取和实际连接就绪分别记录；动画帧不等同于屏幕呈现。

本版没有据此宣称历史性能尖峰已全部解决。现有 200 毫秒性能目标与告警策略保持不变，功能、构建和升级检查仍是发布条件。
