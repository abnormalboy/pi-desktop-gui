# Pi Desktop v0.14.18

本版保留最新主线的独立会话进程、后台任务和运行中设置能力，修复重试记录、会话排序和冷会话显示等待。

- 新一轮有效任务开始时清除上一轮失败、取消或中断留下的重试记录；同一轮的补充消息与排队操作仍保留当前记录，连接启动产生的新通知也保留。
- 查看、连接或重新加载会话不再改变最后活动时间与排序。发送、实际内容变化、工具运行、任务完成及真实中断继续更新活动；后台历史编辑和分支导航完成后仍正确显示未读。
- 首次打开或退出后重连会话时，先显示目标历史和草稿，不再等待 Pi 启动完成才切换页面。Pi 就绪前发送仍受保护；选择调用仍等待自己的保存与连接完成，保存失败不启动新进程。
- 快速往返切换按会话隔离历史、待完成操作与错误，过期读取或连接结果不会覆盖当前会话；同一目标的未完成连接共用结果。
- 更新真实界面验收以覆盖独立会话、冷首访、热切换、草稿与历史隔离、真实外部进程退出及恢复，并保留完整构建和升级检查。

真实 Pi 对照显示，提前显示内容解决了冷连接之前的等待；Pi 进程本身的启动时间没有因此减少。历史上出现的性能尖峰未全部归因，也不承诺所有设备都低于 200 毫秒。现有 200 毫秒目标和超限告警策略保持不变，功能正确性、构建与升级检查仍为硬检查。界面测试区分目标 DOM、下一动画帧、运行时就绪和选择完成，动画帧不等同于屏幕实际呈现。
