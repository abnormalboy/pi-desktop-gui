# Pi Desktop v0.14.9

本版修复长会话结束后聊天内容与原生历史不同步、最终总结漏显示的问题。

## 本版变化

- 会话结束和重新连接时，从 Pi 原生会话文件读取当前分支的完整聊天记录，避免使用压缩后的模型上下文替换界面历史。
- 结束时向窗口完整同步一次消息，补齐可能缺失的最后回复和工具结果；运行中的流式回复继续实时更新。
- 过期的刷新不能覆盖新一轮任务或其他会话的消息。
- 原生历史读取保留扩展消息和分支总结，不修改原会话文件。
- 任务结束后自动收起运行记录，并标为“历史运行记录”；恢复成功的记录不再保留“继续执行”的当前状态文案。
- 增加原生历史同步、刷新竞态及真实 Pi 压缩后的界面回归；覆盖工具执行、最终总结和重启恢复。

## 下载与更新

- Windows x64：推荐 `Pi-Desktop-0.14.9-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.9-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.9-mac-arm64.dmg` / `.zip`；Intel 芯片选择 `Pi-Desktop-0.14.9-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.9-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.9-linux-amd64.deb`。
- `SHA256SUMS.txt` 提供发布文件的 SHA-256 校验值。

本版保留 v0.14.8 的图片识别修复。仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent；macOS 安装包尚未签名、公证，首次打开方式见 README。
