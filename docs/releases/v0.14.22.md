# Pi Desktop v0.14.22

本版将模型列表读取与聊天连接分开，减少重复的运行环境检测，并按 Pi 实际提供的级别保存推理设置。包含 v0.14.21 主线的会话切换、界面与更新恢复修复。

- 打开模型菜单时，通过短时 Pi 进程读取当前项目的模型、项目扩展注册的服务商和推理级别，不加载桌面适配扩展，也不建立聊天连接。读取完成后关闭查询进程；读取失败在菜单中显示原因，并可重新读取。发送任务或主动连接时才建立聊天连接。
- 读取历史对话的模型配置时，使用临时副本恢复 Pi 的分支选择，不修改原始历史文件，也不创建新的聊天记录。已移除的模型偏好仍予以保留，允许用户重新选择模型，不会悄悄替换。
- 复用相同运行环境的检测结果，避免每次启动重复执行版本检查。Pi 入口、运行文件、相关配置或环境路径变化时重新检测；主动检查环境始终重新检测，失败结果不供后续启动复用。
- 推理级别以 Pi 为当前模型返回的列表为准，支持 `max` 及后续新增级别。运行中为下一任务选择模型时，按下一模型的能力校验推理级别；不支持的选择会明确提示并保留原设置。
- 保留主线的新建与切换会话保护：切换完成前模型入口保持禁用，旧菜单和操作仍归原会话所有。

新增真实 Pi 模型目录、历史文件保护、环境缓存刷新和推理级别回归。发布继续执行三平台测试、Windows/Linux 升级回归、安装包及更新元数据校验。
