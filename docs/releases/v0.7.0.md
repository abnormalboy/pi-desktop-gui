# Pi Desktop v0.7.0

新增会话级工具审批、Git 对象快照，并减少长会话流式输出时的重复传输和渲染。

## 本版变化

- 工具审批提供全自动、确认修改、只读三种模式，按会话保存。确认卡片展示命令或文件改动，可允许一次、在本会话内持续允许，或填写原因拒绝。
- 手动 `!` / `!!` 命令同样遵守审批模式；外部工具自报只读不能绕过确认。命令持续授权按完整命令匹配，切换会话或退出确认模式后清除临时授权。
- 修复停止任务后审批模式未生效或影响下一会话的问题。审批卡片保留正在输入的焦点，按 Esc 关闭模式菜单不会误触停止任务。
- Git 项目的本轮快照存入应用数据目录，支持单文件不超过 50 MiB 的二进制内容、原始换行符和 POSIX 文件权限恢复；支持 SHA-1 / SHA-256 仓库及特殊文件名。
- 快照保留最多 7 天，总容量 200 MiB 包含私有 Git 对象。建立快照失败时任务不会开始；变化扫描失败时停止撤销，避免依据不完整的文件列表修改项目。
- 运行状态按消息和工具的变化位置增量同步，消息及 Markdown 组件使用缓存；修复并行工具结束后仍显示运行中，以及刷新窗口后状态同步的问题。

## 使用范围

审批控制经过 Pi 钩子的工具调用，不是操作系统沙箱，不能限制扩展自身执行的代码。确认模式下的“本会话总是允许”对命令按完整文本匹配，对其他工具按工具名授权。

快照仅覆盖 Git 项目中纳入扫描的普通文件，不含凭据、构建目录、符号链接和超出范围的文件，也不能撤销网络请求等外部副作用。项目清理了被快照借用的 Git 对象后，相应内容可能无法恢复。升级前的旧格式快照不能沿用，需要开始新任务建立基线；快照不能替代备份。

## 下载与运行

- Windows x64：下载 `Pi-Desktop-0.7.0-win-x64.exe`，关闭旧版本后双击运行。
- macOS：按芯片选择 `arm64` 或 `x64` 的 `.dmg` / `.zip`。
- Linux x64：选择 `.AppImage` 或 `.deb`。
- `SHA256SUMS.txt` 提供所有安装包的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent 1.1.0：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@1.1.0
```

Windows 还需要 Git for Windows。macOS 安装包暂未签名、公证，首次打开方式见仓库 README；Linux AppImage 首次运行需授予执行权限。安装包不包含 Pi CLI 或模型账户凭据。
