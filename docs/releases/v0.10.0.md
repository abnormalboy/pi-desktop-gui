# Pi Desktop v0.10.0

本版改善同项目会话切换，并把模型请求失败转成可操作的中文提示；同时正式发布此前 v0.8.0、v0.9.0 已验收的恢复、模块化和应用更新功能。

**从 v0.7.0 或更早版本升级，请先手动下载安装本版。** Windows 推荐 `Pi-Desktop-0.10.0-win-x64-setup.exe` 安装版，按用户安装，无需管理员权限。安装版与便携版沿用原数据目录；之后 Windows 安装版和 Linux AppImage 可在应用内下载并安装新版本。

### 会话切换与错误处理

- 同一工作目录内切换已有会话或创建会话时复用 Pi 进程，恢复各会话自己的历史、模型、推理级别、标题和审批模式。跨项目或独立对话目录变化时仍重新启动，保证项目扩展使用正确目录。
- 扩展取消切换时保留原会话；切换失败或 Pi 已退出时重新连接恢复。诊断显示最近一次切换方式、耗时和重启原因。
- 修复切换期间旧扩展事件可能覆盖目标草稿的问题；切走再切回也不会恢复之前的“总是允许”审批。
- 模型错误分为凭据、额度、繁忙、上下文、模型不可用、网络和未知错误，提供对应设置或处理按钮。
- 同一类模型错误连续失败三次起显示次数。仍只使用 Pi 自带重试，不额外自动重试或替换模型。
- 错误详情可展开、复制；界面和诊断中的常见凭据会隐藏，重新打开历史也会处理错误文本。Pi 原始 JSONL 文件保持原样。
- 进程启动与会话绑定分开，分类逻辑与错误卡片独立；新增真实 Pi、界面操作和 Windows/macOS 发布构建切换测试。

### 本次一并提供的恢复与更新能力

- 本地会话索引损坏时保留原文件并尝试恢复备份，坏项目或会话逐条处理；数据目录无法写入时停止发送，避免任务先执行、数据却未保存。
- Pi 意外退出时保留历史与待发送草稿，显示退出原因、最后工具、日志和文件变更，提供重连、编辑后继续与撤销入口。无法确认残留命令已结束时暂停恢复和撤销。
- 界面、状态处理、Pi 协议与平台适配分开；Pi 版本不支持或协议改变时明确提示，不猜测新旧字段。
- 应用启动后检查更新，也可在“设置 → 关于与更新”手动检查。Windows 安装版与 Linux AppImage 支持下载后重启安装，执行任务或等待审批时不能直接重启。
- macOS、Linux deb 和 Windows 便携版提示新版本并打开下载页面。升级前保留本地索引备份，遇到不认识的新数据格式时只读打开。

Pi CLI 支持范围为 1.1.x，本版不会安装或升级 Pi。Windows 与 macOS 安装包尚未签名；macOS 保持手动下载安装。下载页附有 SHA-256 校验清单，应用更新同时核对 SHA-512。
