# Pi Desktop v0.10.0

本版改善同项目会话切换，并把模型请求失败转成可操作的中文提示。

- 同一工作目录内切换已有会话或创建会话时复用 Pi 进程，恢复各会话自己的历史、模型、推理级别、标题和审批模式。跨项目或独立对话目录变化时仍重新启动，保证项目扩展使用正确目录。
- 扩展取消切换时保留原会话；切换失败或 Pi 已退出时重新连接恢复。诊断显示最近一次切换方式、耗时和重启原因。
- 修复切换期间旧扩展事件可能覆盖目标草稿的问题；切走再切回也不会恢复之前的“总是允许”审批。
- 模型错误分为凭据、额度、繁忙、上下文、模型不可用、网络和未知错误，提供对应设置或处理按钮。
- 同一类模型错误连续失败三次起显示次数。仍只使用 Pi 自带重试，不额外自动重试或替换模型。
- 错误详情可展开、复制；界面和诊断中的常见凭据会隐藏，重新打开历史也会处理错误文本。Pi 原始 JSONL 文件保持原样。
- 进程启动与会话绑定分开，分类逻辑与错误卡片独立；新增真实 Pi、界面操作和 Windows/macOS 发布构建切换测试。

Pi CLI 支持范围保持 1.1.x，本版不会安装或升级 Pi。应用更新与安装方式沿用 v0.9.0。
