# Pi Desktop v0.9.0

本版增加应用更新。旧版用户需要手动安装本版一次，之后 Windows 安装版和 Linux AppImage 可以在应用内下载并安装新版本。

- Windows 新增 `Pi-Desktop-0.9.0-win-x64-setup.exe` 安装版，按用户安装，无需管理员权限；原便携版继续提供。两种方式沿用同一数据目录。
- 启动 10 秒后检查更新，此后每 6 小时检查一次；也可在“设置 → 关于与更新”立即检查。支持自动更新的安装方式默认后台下载，可以关闭。
- 下载完成后，侧栏显示“重启以更新”，点击查看本次更新说明，再选择立即重启或稍后。稍后会在下次正常退出时安装；任务执行中或有待确认审批时不允许直接重启。
- macOS、Linux deb 和 Windows 便携版提示新版本，并提供对应版本的下载页面。便携版提示可改用安装版。
- 网络或下载校验失败不弹窗打扰，在“关于与更新”显示原因和重试入口。安装前等待草稿与索引保存完成。
- 升级首次启动前保留原始索引，最多三份；遇到不认识的较新数据格式时只读打开，不改写原文件。
- 更新策略、原生更新器适配和界面分开，独立于 Pi 的进程与消息协议；新增真实安装包升级回归和发布清单校验。

当前 Windows 与 macOS 安装包尚未签名。Windows 下载更新使用 SHA-512 检查文件完整性；macOS 仍需手动下载安装。Pi CLI 的安装和升级继续由用户管理，本次应用更新不会替换 Pi。
