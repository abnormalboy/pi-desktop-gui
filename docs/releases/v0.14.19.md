# Pi Desktop v0.14.19

本版将浏览对话与连接 Pi 分开，消除仅切换对话就出现“启动中 0:00”和任务运行控件的问题。

- 打开或切换对话只恢复历史、草稿和已有运行状态，不再自动启动 Pi；新建的空对话也不会自动连接。
- 发送首条任务时按需连接；主动打开模型菜单或点击连接时，仍读取 Pi 的真实模型和推理配置，保留已保存的会话选择及项目默认设置。
- 已连接的对话继续复用各自的 Pi 进程，切走后后台任务继续运行；切回不会重启任务或清空队列。
- 连接期间显示“正在连接 Pi”和“取消连接”，隐藏任务计时及“立即补充”；真正执行任务时保留原有计时和补充方式。
- Pi 意外退出后仍可先浏览已保存的历史，再主动恢复连接；快速切换时，历史、草稿和错误继续按对话隔离。

更新了会话选择、首次发送、连接状态、模型菜单和打包版界面验收。发布流程继续执行三平台测试、Windows/Linux 升级回归、安装包与更新清单校验。

本机隔离验收中，热切换点击至目标历史进入页面并经过下一动画帧约为 26～30 毫秒，首次跨目录浏览约为 28～45 毫秒；该结果不代表所有设备或超长历史的耗时，动画帧也不等同于屏幕实际呈现。
