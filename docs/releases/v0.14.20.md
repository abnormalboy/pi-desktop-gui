# Pi Desktop v0.14.20

本版改进错误重试、用量说明和空对话导出提示，保留 v0.14.19 的按需连接行为。

- 连续的空正文错误只展开显示最新一条；相同错误显示次数，前序失败记录可以展开。搜索、重新生成和原始会话记录仍保留各条消息的位置；包含正文、思考、图片或工具调用的失败不会折叠丢失。
- 明确区分当前上下文/窗口容量与会话累计 Token，补充输入、输出、缓存读取、缓存写入和估算费用。缓存比例按输入 Token 计算，不等同于请求命中率；窗口剩余也不承诺自动压缩触发位置。未知数据不会显示成零。
- 新空对话以及本次明确连接后尚未生成记录的空对话，导出 HTML/JSONL 会提示“会话尚未产生可导出的内容”。已有历史丢失、格式损坏、权限错误仍如实报错；运行中导出的快照行为保持不变。

修复通过单元回归、真实 Pi 本地模型接口对照和既有界面验收流程验证。发布继续执行三平台检查、Windows/Linux 升级回归、打包和更新清单校验。

本版不宣称所有会话切换性能尖峰已经解决。退出或重启后，无法确认来源的缺失记录仍按真实文件错误处理，避免将历史丢失误报为空对话。
