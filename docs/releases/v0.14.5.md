# Pi Desktop v0.14.5

本版让配置好模型后的新会话自动连接 Pi，直接显示实际选中的模型和推理深度。

## 本版变化

- 新建对话时自动读取 Pi 的实际模型，下拉列表同步显示选中项，无需先发送消息或手动打开模型选择器；应用重启后，尚未连接 Pi 时新建对话也适用。
- 保留已保存的模型偏好；未保存偏好时使用 Pi 的实际默认配置，包含项目设置，不把上一条会话的显示内容当作默认值。
- 初始化只读取本机 Pi 状态，不发送模型请求。其他任务运行时等待其结束，未启用项目、不可写数据及进程清理状态继续遵守原有连接限制；索引无法恢复时保留手动连接，连接失败后可手动重试。
- 扩充真实 Pi 界面回归，检查模型勾选、冷启动、实际请求使用的模型、项目信任及运行中任务保护。

## 下载与更新

- Windows x64：推荐使用 `Pi-Desktop-0.14.5-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.5-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.5-mac-arm64.dmg` / `.zip`，Intel 芯片选择 `Pi-Desktop-0.14.5-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.5-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.5-linux-amd64.deb`。
- Windows 安装版和 Linux AppImage 支持应用内更新；其他安装方式请从发布页下载。`SHA256SUMS.txt` 提供发布资产的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent。完整功能回归使用 Pi 1.1.0；本版不会自动安装或升级 Pi。macOS 安装包仍未签名、公证，首次打开方式见 README。

## 验证边界与已知问题

- Pi 1.3.0 的完整功能兼容性尚未验证。
- 三平台原生菜单与系统主题的实机人工验收仍待完成；[#1](https://github.com/yeyuProject/pi-desktop-gui/issues/1) 保持开启。
- 历史会话切换性能尖峰仍在调查，200 毫秒目标继续采样，超限暂作可见告警。本版不承诺所有切换低于 200 毫秒。
