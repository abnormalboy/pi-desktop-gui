# Pi Desktop v0.14.10

本版修复 Windows 目录版缺少自动更新配置、检查更新时误报网络问题的情况。

## 本版变化

- Windows 打包时按已有的 GitHub 发布仓库自动生成更新配置，`win-unpacked` 目录版也能从 `yeyuProject/pi-desktop-gui` 检查和下载更新，无需手动填写仓库地址。
- 更新配置包含原生更新器所需的下载缓存目录及适用的签名校验信息，沿用安装版的配置生成流程。
- 缺少更新配置时明确提示安装包问题，避免统一显示为“请检查网络”。
- 增加真实原生更新器的回归测试，覆盖配置缺失、生成配置读取和下载缓存路径。

## 下载与更新

- Windows x64：推荐 `Pi-Desktop-0.14.10-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.10-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.10-mac-arm64.dmg` / `.zip`；Intel 芯片选择 `Pi-Desktop-0.14.10-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.10-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.10-linux-amd64.deb`。
- `SHA256SUMS.txt` 提供发布文件的 SHA-256 校验值。

本版保留 v0.14.9 的原生会话历史同步及此前的图片识别修复。仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent；macOS 安装包尚未签名、公证，首次打开方式见 README。
