# Pi Desktop v0.6.0

本版新增 macOS 与 Linux 支持，并完善桌面交互、终端交接和文件撤销。

- Windows x64：便携 `.exe`，双击运行。
- macOS：提供 Apple Silicon（arm64）和 Intel（x64）的 `.dmg` 与 `.zip`。
- Linux x64：提供 `.AppImage` 与 `.deb`。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

## 本版变化

- 适配 macOS 菜单、⌘ 快捷键、标题栏与窗口关闭习惯；从系统桌面启动时读取登录 shell 的 PATH。
- 在各系统的外部终端继续同一 Pi 会话；启动失败和异常退出后自动解除交接锁。
- 强制结束时清理 Pi 启动的独立子进程组，避免命令继续修改文件。
- 支持后台通知、窗口位置恢复、提问历史和快捷键速查。
- 拖入项目文件时保留校验期间新增的草稿文字及附件删除操作；切换会话会取消未完成的添加。
- 支持内联 Diff、运行期间文件变更的撤销、会话树和常用 Pi 配置。

## 运行要求

需要本机安装 Node.js 22.19 或更高版本，以及 Pi Coding Agent 1.1.0：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@1.1.0
```

Windows 还需要 Git for Windows。桌面安装包不包含 Pi CLI、模型服务或账户凭据。

macOS 安装包目前未签名、未公证，首次打开方式见仓库 README。Linux AppImage 需要先授予执行权限。文件撤销只覆盖纳入运行基线的文件，不会撤销命令对外部服务产生的操作。
