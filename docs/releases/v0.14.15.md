# Pi Desktop v0.14.15

本版修复一个会话运行时阻止其他会话发送的问题，并明确运行中修改设置的生效时间。

- 每个会话使用独立 Pi 进程。后台任务继续执行，输出、队列、审批、重试和错误按会话隔离；停止默认只作用于当前会话，另设“停止所有会话”。
- 运行中可以修改模型和推理级别，界面显示本轮与下次设置。新设置在下一次用户发送新任务时生效，工具继续推理和运行中补充仍沿用本轮设置。
- 审批模式影响后续工具；MCP、Skills 和扩展配置可随时保存，在相关会话安全后加载。Pi、Node 等路径在下次进程启动时使用。
- 运行中可以查看历史、会话树、文件、差异和用量，也可以创建独立历史分支，或导出点击时已经产生的内容。
- 文件撤销和目录修改检查实际共用目录及写入目标，保留 Git、文件版本、存储和进程保护；无关项目互不阻塞。
- 按场景显示停止、取消重试、恢复和项目操作；暂时冲突的功能保留原因及入口。
- 自动重试恢复后清除会话中的旧错误提示，使用会自动消失的“连接已恢复”通知；最终失败和取消仍保留相应记录。

验证覆盖真实 Pi 双会话并发、审批归属、单会话停止、模型和推理实际生效时点、配置安全加载、流式导出，以及设置界面的异步竞争。各项操作规则见 [运行中的操作规则](https://github.com/yeyuProject/pi-desktop-gui/blob/v0.14.15/docs/runtime-operations.md)。

Pi 原生 RPC 目前只能通过停止当前操作来取消压缩，因此按钮明确标注“停止当前压缩及任务”。
