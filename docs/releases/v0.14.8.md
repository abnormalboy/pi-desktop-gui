# Pi Desktop v0.14.8

本版修复图片在缺少系统类型信息时，被误当成文本引用并触发 256 KiB 提示的问题。

## 本版变化

- 拖放和粘贴会识别图片内容，支持缺少类型信息、类型为通用二进制或没有扩展名的 PNG、JPEG、WebP、GIF 图片。
- 通过 `@` 或工作区引用项目图片时，会添加为图片附件；文本文件继续使用原有的引用及行范围功能。
- 图片选择器同样按实际格式读取图片，异步选择不会覆盖选择期间修改的草稿或已移除的附件。
- 保留项目边界、凭据文件保护及图片数量、大小校验：最多 8 张、单张 8 MiB、总计 16 MiB。不支持的格式或无法识别的图片显示图片格式错误。
- 增加图片识别单元测试和真实 Pi 收图回归，并在 Windows、macOS 打包应用及 Linux 界面中验证图片入口。

## 下载与更新

- Windows x64：推荐使用 `Pi-Desktop-0.14.8-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.8-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.8-mac-arm64.dmg` / `.zip`，Intel 芯片选择 `Pi-Desktop-0.14.8-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.8-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.8-linux-amd64.deb`。
- Windows 安装版和 Linux AppImage 支持应用内更新；其他安装方式请从发布页下载。`SHA256SUMS.txt` 提供发布资产的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent。完整功能回归使用 Pi 1.1.0；本版不会自动安装或升级 Pi。macOS 安装包仍未签名、公证，首次打开方式见 README。

图片能否被模型理解还取决于所选模型及供应商的图片能力；本版修复本地附件识别，不改变模型的能力声明。
