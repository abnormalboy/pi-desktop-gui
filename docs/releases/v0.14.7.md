# Pi Desktop v0.14.7

本版修复自动重试的状态显示和取消行为。模型连接失败后，等待响应的重试会持续显示当前进度；已恢复的记录不再一直显示“正在重试”。

## 本版变化

- 重试请求开始后继续显示重试横幅、当前次数和等待模型响应的时间，直到恢复、失败或取消。
- 同一次失败的多次尝试更新同一条运行记录，结束后明确显示已恢复、失败或取消，避免旧提示累积造成仍在重试的错觉。
- “取消重试”现在同时支持倒计时和请求已发出的阶段，使用正常停止流程取消请求并恢复尚未发送的消息。
- 增加真实 Pi 的断线恢复、工具继续执行、重试耗尽、两阶段取消及配置超时回归，以及桌面界面的恢复与取消测试。

## 下载与更新

- Windows x64：推荐使用 `Pi-Desktop-0.14.7-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.7-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.7-mac-arm64.dmg` / `.zip`，Intel 芯片选择 `Pi-Desktop-0.14.7-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.7-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.7-linux-amd64.deb`。
- Windows 安装版和 Linux AppImage 支持应用内更新；其他安装方式请从发布页下载。`SHA256SUMS.txt` 提供发布资产的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent。完整功能回归使用 Pi 1.1.0；本版不会自动安装或升级 Pi。macOS 安装包仍未签名、公证，首次打开方式见 README。

## 验证边界

- 本版不修改模型服务的全局超时或重试设置。长时间等待上游响应仍受 Pi 和模型服务的配置影响。
- 隔离测试验证真实 Pi 的连接故障恢复，不等同于保证所有第三方模型服务始终可用。
