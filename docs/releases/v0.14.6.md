# Pi Desktop v0.14.6

本版让新会话直接使用 Pi 的原生目录，便于 CC Switch 等工具发现会话及统计用量。

## 本版变化

- 新的项目会话和独立对话由 Pi 决定日志位置，默认保存到 `~/.pi/agent/sessions/<工作目录编码>/`，不再强制写入桌面应用的数据目录。
- 保留 Pi 的 `sessionDir` 配置及环境变量覆盖；在终端继续会话时使用相同的目录规则。
- 已有桌面版会话仍可从原位置继续打开。打开旧会话后新建同项目会话，会重新读取 Pi 的原生目录，避免继承旧的桌面日志目录。
- 增加真实 Pi 回归，覆盖项目与独立对话的目录、旧历史恢复、新会话目录及自定义 `sessionDir`。

## 下载与更新

- Windows x64：推荐使用 `Pi-Desktop-0.14.6-win-x64-setup.exe`；便携版为 `Pi-Desktop-0.14.6-win-x64.exe`。
- macOS：Apple 芯片选择 `Pi-Desktop-0.14.6-mac-arm64.dmg` / `.zip`，Intel 芯片选择 `Pi-Desktop-0.14.6-mac-x64.dmg` / `.zip`。
- Linux x64：选择 `Pi-Desktop-0.14.6-linux-x86_64.AppImage` 或 `Pi-Desktop-0.14.6-linux-amd64.deb`。
- Windows 安装版和 Linux AppImage 支持应用内更新；其他安装方式请从发布页下载。`SHA256SUMS.txt` 提供发布资产的 SHA-256 校验值。

仍需本机安装 Node.js 22.19 或更高版本及 Pi Coding Agent。完整功能回归使用 Pi 1.1.0；本版不会自动安装或升级 Pi。macOS 安装包仍未签名、公证，首次打开方式见 README。

## 验证边界与已知问题

- 已有日志保持原位置可用，不会自动修改 Pi 全局配置或搬迁全部旧历史；统计工具需要能够扫描对应目录。
- 用量依据 Pi 日志和统计工具的定价信息，不能视为供应商账单。
- Pi 1.3.0 的完整功能兼容性尚未验证；三平台原生菜单与系统主题的实机人工验收仍待完成。
- 历史会话切换性能尖峰仍在调查，200 毫秒目标继续采样，超限暂作可见告警。本版不承诺所有切换低于 200 毫秒。
