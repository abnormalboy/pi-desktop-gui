## Direct evidence

- The #10 grouping assertions failed before the change (four visible items instead of two), then passed with the original transcript unchanged.
- With actual Pi 1.1.0 and an isolated local provider, two requests produced cumulative usage of 120 then 240 tokens while estimated current context stayed at 120. Per request: input 30, output 20, cache read 60 and cache write 10. Reported zero cost remained zero.
- Before #14, explicitly connecting a fresh empty session assigned a nonexistent file; both export formats returned ENOENT with zero model requests. After the change, both returned “会话尚未产生可导出的内容”, still with zero model requests. Sending a message then allowed normal HTML and JSONL exports.
- Review caught and corrected a caller that hid zero/unknown totals, a Node-only JSX test import/typing problem, the active-search/history-toggle interaction, and retiring empty-export provenance after a corrupt-file read. These intermediate failures were not reported as successful acceptance.

Local environment: Linux, Node 24.19.0, pinned Pi 1.1.0. CI uses Node 22.22.0.

- `npm test`: 332 tests, 331 passed, one platform skip, zero failures.

- Focused export/transcript/retry tests: 53 passed; final independent export/usage/layout/search/protocol/lazy-connect review run: 96 passed.

Local Electron/Chromium interaction could not be executed in the available isolated runtime (browser socket restrictions and missing writable default Electron cache). No local native UI pass is claimed. The existing Linux CI feature suite executes the new retry and context UI cases; the existing screenshot step regenerates README previews as acceptance artifacts. Windows/macOS packaged session checks, three-platform functional tests and Windows/Linux upgrade checks remain mandatory.

## CI evidence and limitations

This file accompanies the candidate. Branch CI, exact-main CI and the formal release each need their own successful run; a branch result is not proof of publication. The final run links and artifact names accompany the merge/release acceptance report once available.

Expected relevant UI outputs are in the `acceptance-ubuntu-latest` artifact: `output/playwright/retry-ui-linux/` (including `collapsed-failures.png` and `result.json`), `test-results/conversation-v014/`, and `output/playwright/readme/`.

The cache percentage is a fraction of input tokens, not request-level cache hit rate. Remaining context window is not the automatic-compaction threshold. The export guard deliberately does not guess whether an unknown missing file after disconnect/restart once contained history. Historical performance spikes and unverified native Windows 10 issue reports are outside this patch.
